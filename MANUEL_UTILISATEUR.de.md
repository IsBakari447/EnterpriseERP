# EnterpriseERP Benutzerhandbuch

Diese Anleitung erklärt, wie EnterpriseERP im Alltag benutzt wird. Sie ist für normale Benutzer, Verantwortliche, Verkäufer und Administratoren geschrieben. Programmierkenntnisse sind nicht nötig.

## 1. Wofür ist EnterpriseERP?

EnterpriseERP hilft, die Arbeit eines Unternehmens an einem Ort zu organisieren.

Sie können:

- Kunden speichern;
- Lieferanten speichern;
- Produkte hinzufügen;
- Lager verfolgen;
- Angebote erstellen;
- Rechnungen erstellen;
- Zahlungen erfassen;
- Ausgaben verfolgen;
- Mitarbeiter und Anwesenheit verwalten;
- das Dashboard ansehen;
- Daten exportieren;
- wichtige Aktionen nachvollziehen.

## 2. Vor der Anmeldung

Auf der Startseite können Sie:

- dieses Handbuch lesen;
- die Hauptfunktionen sehen;
- die Demo öffnen;
- die mobile App herunterladen, wenn verfügbar;
- ein Konto erstellen;
- sich anmelden.

## 3. Anmelden

1. Klicken Sie auf **Anmelden**.
2. Geben Sie Ihre E-Mail ein.
3. Geben Sie Ihr Passwort ein.
4. Bestätigen Sie.

Wenn Sie kein Konto haben, klicken Sie auf **Konto erstellen**.

## 4. Dashboard verstehen

Das Dashboard ist die erste Seite nach der Anmeldung.

Es zeigt:

- Kunden;
- Produkte;
- Rechnungen;
- Zahlungen;
- Ausgaben;
- Warnungen;
- letzte Aktivitäten.

## 5. Kunde hinzufügen

1. Öffnen Sie **Kunden**.
2. Klicken Sie auf **Hinzufügen**.
3. Füllen Sie Name, Telefon, E-Mail und Adresse aus.
4. Speichern Sie.

## 6. Lieferant hinzufügen

1. Öffnen Sie **Lieferanten**.
2. Klicken Sie auf **Hinzufügen**.
3. Füllen Sie die Kontaktdaten aus.
4. Speichern Sie.

## 7. Produkt hinzufügen

1. Öffnen Sie **Produkte**.
2. Klicken Sie auf **Produkt hinzufügen**.
3. Geben Sie den Namen ein.
4. Wählen Sie die Kategorie.
5. Geben Sie den Einkaufspreis ein.
6. Geben Sie den Verkaufspreis ein.
7. Geben Sie die Menge ein.
8. Speichern Sie.

Kategorien:

- **EnterpriseERP**
- **Mobile**
- **Cloud**

## 8. Lager verwalten

Benutzen Sie **Lager**, um Ein- und Ausgänge zu verfolgen.

Prüfen Sie das Lager regelmäßig, um Engpässe zu vermeiden.

## 9. Angebot erstellen

1. Öffnen Sie **Angebote**.
2. Klicken Sie auf **Erstellen**.
3. Wählen Sie den Kunden.
4. Fügen Sie Produkte oder Dienstleistungen hinzu.
5. Prüfen Sie Preise und Mengen.
6. Speichern Sie.
7. Laden Sie bei Bedarf die PDF herunter oder drucken Sie sie.

## 10. Rechnung erstellen

1. Öffnen Sie **Rechnungen**.
2. Klicken Sie auf **Erstellen**.
3. Wählen Sie den Kunden.
4. Fügen Sie Produkte oder Dienstleistungen hinzu.
5. Prüfen Sie den Gesamtbetrag.
6. Speichern Sie.
7. Drucken oder laden Sie die PDF herunter.

## 11. Zahlung erfassen

1. Öffnen Sie **Zahlungen**.
2. Klicken Sie auf **Zahlung hinzufügen**.
3. Wählen Sie die Rechnung.
4. Geben Sie den bezahlten Betrag ein.
5. Wählen Sie die Zahlungsart.
6. Fügen Sie eine Referenz hinzu, falls vorhanden.
7. Speichern Sie.

## 12. Ausgaben verfolgen

Ausgaben sind Geld, das das Unternehmen verlässt.

Beispiele:

- Material;
- Transport;
- Gehälter;
- Abonnements;
- Verwaltung.

## 13. Mitarbeiter und Anwesenheit

Benutzen Sie **Mitarbeiter** für Personen im Unternehmen.

Benutzen Sie **Anwesenheit** für Kommen und Gehen.

## 14. Exporte

Exporte erstellen Dateien für Excel, Buchhaltung oder Berichte.

## 15. Sicherheit

Gute Gewohnheiten:

- starkes Passwort verwenden;
- Konto nicht teilen;
- regelmäßig sichern;
- richtige Rollen vergeben;
- wichtige Aktionen prüfen.

## 16. Rollen und Rechte

Rollen bestimmen, was Benutzer tun können.

Wenn ein Menü fehlt, prüfen Sie die Rechte.

## 17. Mobile App

Mit der mobilen App können Sie EnterpriseERP vom Telefon aus nutzen.

## 18. Häufige Fragen

### Ich sehe ein Menü nicht

Vielleicht fehlen Rechte. Fragen Sie den Administrator.

### Ich kann nicht speichern

Prüfen Sie die Pflichtfelder.

### Eine Rechnung bleibt offen

Sie ist vielleicht noch nicht vollständig bezahlt.

## 19. Empfohlene Routine

Jeden Tag:

- Dashboard prüfen;
- Zahlungen ansehen;
- offene Rechnungen prüfen;
- Verkäufe oder Ausgaben hinzufügen;
- Lagerwarnungen prüfen.

## 20. Kurze Zusammenfassung

1. Kunden hinzufügen.
2. Produkte hinzufügen.
3. Lager verfolgen.
4. Angebote und Rechnungen erstellen.
5. Zahlungen erfassen.
6. Ausgaben verfolgen.
7. Dashboard lesen.
8. Wichtige Daten exportieren.
