# Manuel utilisateur EnterpriseERP

Ce guide explique comment utiliser EnterpriseERP au quotidien. Il est ecrit pour les utilisateurs, les responsables, les vendeurs, les administrateurs et toute personne qui veut comprendre l'application sans connaitre la programmation.

## 1. A quoi sert EnterpriseERP ?

EnterpriseERP aide une entreprise a organiser son travail depuis un seul endroit.

Avec EnterpriseERP, vous pouvez :

- enregistrer vos clients ;
- enregistrer vos fournisseurs ;
- ajouter vos produits ;
- suivre le stock ;
- creer des devis ;
- creer des factures ;
- enregistrer les paiements ;
- suivre les depenses ;
- gerer les employes et les presences ;
- consulter le tableau de bord ;
- exporter des donnees ;
- garder une trace des actions importantes.

## 2. Avant de se connecter

Sur la page d'accueil, vous pouvez deja :

- lire ce manuel ;
- voir les fonctions principales ;
- consulter la demonstration ;
- telecharger l'application mobile si elle est disponible ;
- creer un compte ;
- vous connecter.

Si vous decouvrez EnterpriseERP pour la premiere fois, commencez par lire les sections suivantes :

1. Connexion
2. Tableau de bord
3. Clients
4. Produits et stock
5. Devis, factures et paiements

## 3. Se connecter

1. Cliquez sur **Connexion**.
2. Entrez votre email.
3. Entrez votre mot de passe.
4. Cliquez sur le bouton de connexion.

Si vous n'avez pas encore de compte, cliquez sur **Creer un compte**.

## 4. Comprendre le tableau de bord

Le tableau de bord est la premiere page apres connexion.

Il donne une vue rapide de l'entreprise :

- nombre de clients ;
- produits disponibles ;
- factures ;
- paiements ;
- depenses ;
- alertes ;
- activite recente.

Utilisez cette page chaque jour pour voir rapidement ce qui demande votre attention.

## 5. Ajouter un client

Un client est une personne ou une entreprise qui achete vos produits ou services.

Pour ajouter un client :

1. Ouvrez le menu **Clients**.
2. Cliquez sur **Ajouter** ou **Nouveau client**.
3. Remplissez les informations utiles : nom, telephone, email, adresse.
4. Enregistrez.

Conseil : ajoutez au minimum le nom et un moyen de contact.

## 6. Ajouter un fournisseur

Un fournisseur est une personne ou une entreprise qui vous vend des produits ou services.

Pour ajouter un fournisseur :

1. Ouvrez le menu **Fournisseurs**.
2. Cliquez sur **Ajouter**.
3. Remplissez le nom, le contact, le telephone, l'email ou l'adresse.
4. Enregistrez.

## 7. Ajouter un produit

Un produit est un article ou un service que votre entreprise vend ou gere en stock.

Pour ajouter un produit :

1. Ouvrez le menu **Produits**.
2. Cliquez sur **Ajouter un produit**.
3. Entrez le nom du produit.
4. Choisissez la categorie.
5. Entrez le prix d'achat si vous le connaissez.
6. Entrez le prix de vente.
7. Entrez la quantite disponible.
8. Enregistrez.

Les categories disponibles sont :

- **EnterpriseERP**
- **Mobile**
- **Cloud**

Ces categories permettent de ranger les produits et services plus facilement.

## 8. Gerer le stock

Le stock indique les quantites disponibles.

Utilisez le menu **Stock** pour suivre les entrees et sorties.

Exemples :

- entree de stock : vous avez achete ou recu des produits ;
- sortie de stock : vous avez vendu ou utilise des produits.

Verifiez regulierement le stock pour eviter les ruptures.

## 9. Creer un devis

Un devis est une proposition envoyee a un client avant la vente.

Pour creer un devis :

1. Ouvrez le menu **Devis**.
2. Cliquez sur **Creer**.
3. Choisissez le client.
4. Ajoutez les produits ou services.
5. Verifiez les prix et les quantites.
6. Enregistrez.
7. Telechargez ou imprimez le PDF si necessaire.

Un devis peut ensuite etre transforme en facture selon le fonctionnement de votre entreprise.

## 10. Creer une facture

Une facture confirme une vente.

Pour creer une facture :

1. Ouvrez le menu **Factures**.
2. Cliquez sur **Creer**.
3. Choisissez le client.
4. Ajoutez les produits ou services.
5. Verifiez le montant total.
6. Enregistrez.
7. Imprimez ou telechargez la facture en PDF.

## 11. Enregistrer un paiement

Un paiement sert a indiquer qu'un client a paye une facture.

Pour enregistrer un paiement :

1. Ouvrez le menu **Paiements**.
2. Cliquez sur **Ajouter un paiement**.
3. Choisissez la facture concernee.
4. Entrez le montant paye.
5. Choisissez la methode de paiement : espece, carte, virement, Swish ou Mobile Money.
6. Ajoutez une reference si vous en avez une.
7. Enregistrez.

Apres l'enregistrement, EnterpriseERP met a jour le statut de la facture :

- **Paid** si la facture est totalement payee ;
- **Pending** si elle n'est pas encore totalement payee.

## 12. Suivre les depenses

Les depenses representent l'argent qui sort de l'entreprise.

Exemples :

- achat de materiel ;
- transport ;
- salaires ;
- abonnements ;
- frais administratifs.

Pour ajouter une depense :

1. Ouvrez le menu **Depenses**.
2. Cliquez sur **Ajouter**.
3. Indiquez le titre, la categorie, le montant, la date et la methode de paiement.
4. Enregistrez.

## 13. Gerer les employes et presences

Le module employes permet d'enregistrer les personnes qui travaillent dans l'entreprise.

Le module presences permet de suivre les arrivees et sorties.

Utilisez ces menus pour :

- ajouter un employe ;
- consulter la liste des employes ;
- enregistrer une presence ;
- verifier qui est present aujourd'hui.

## 14. Utiliser les exports

Les exports permettent de recuperer vos donnees dans un fichier.

Ils sont utiles pour :

- garder une copie ;
- partager avec un comptable ;
- analyser dans Excel ;
- preparer un rapport.

Ouvrez le menu **Exports** puis choisissez le type de donnees a exporter.

## 15. Sauvegardes et securite

EnterpriseERP contient des outils pour proteger vos donnees.

Bonnes habitudes :

- utilisez un mot de passe solide ;
- ne partagez pas votre compte ;
- sauvegardez regulierement les donnees ;
- donnez les bons roles aux utilisateurs ;
- verifiez les actions importantes dans l'audit.

## 16. Roles et permissions

Les roles permettent de choisir ce qu'un utilisateur peut faire.

Exemples :

- un administrateur peut gerer presque toute l'application ;
- un employe peut avoir un acces limite ;
- un responsable peut voir les rapports et valider certaines actions.

Si un utilisateur ne voit pas un menu, il faut verifier ses permissions.

## 17. Utiliser l'application mobile

L'application mobile sert a consulter et utiliser EnterpriseERP depuis un telephone.

Elle peut etre utile pour :

- consulter les clients ;
- suivre les factures ;
- enregistrer ou verifier des paiements ;
- voir des donnees importantes en deplacement.

Si vous utilisez un telephone connecte au meme reseau que votre ordinateur, demandez l'adresse de connexion correcte a l'administrateur.

## 18. Questions frequentes

### Je ne vois pas un menu

Votre compte n'a peut-etre pas la permission. Demandez a un administrateur de verifier votre role.

### Je ne peux pas enregistrer

Verifiez que tous les champs obligatoires sont remplis. Si le probleme continue, contactez l'administrateur.

### Une facture reste en attente

La facture n'est peut-etre pas totalement payee. Verifiez le montant total et les paiements deja enregistres.

### Le stock est incorrect

Verifiez les entrees et sorties de stock. Corrigez les mouvements si necessaire.

### Je veux imprimer un document

Ouvrez le devis ou la facture puis utilisez le bouton PDF ou impression.

## 19. Routine conseillee

Chaque jour :

- regarder le tableau de bord ;
- verifier les paiements recents ;
- verifier les factures en attente ;
- ajouter les nouvelles ventes ou depenses ;
- controler les alertes de stock.

Chaque semaine :

- verifier les clients actifs ;
- verifier le stock ;
- exporter les donnees importantes ;
- consulter les rapports.

Chaque mois :

- controler les revenus et depenses ;
- sauvegarder les donnees ;
- verifier les utilisateurs et permissions ;
- preparer les rapports de gestion.
